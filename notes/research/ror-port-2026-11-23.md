# RoR-Port (RaikoDenpa, GPL-3.0), checked 2026-11-23

A static recompilation (PS2Recomp) of the PAL release SLES-542.18 with
hand-written PC replacements for file I/O, threads/vsync, input, rendering
(PCSX2's GS code), movies, sound, memory card and window. Chapters 1-2
playable. Not a decompilation; its seam list is a map for our port phase.

Its Ghidra scripts carry ~400 hand-identified, descriptive names (PAL
addresses, each with evidence). tools/map_pal_names.py maps them to NTSC:
the PAL code is shifted by a delta that changes along the binary (e.g.
-0x18DC in the script VM at 0x21xxxx); for each name the delta that puts
most of its 7 neighbours on our function starts is used. 136 map (127 of
them the script VM, sequence/sequence.cpp), 130 of those are unnamed here;
12 of 14 whose evidence cites a constant have it in our asm. The result
(build/ror_port_names.tsv) is a lead list and is not committed: the names
are the port's own guesses and the project is GPL. Clone kept outside the
repo in ../ext/ror-port.
